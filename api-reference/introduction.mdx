## Welcome to the OpenSource Together API

The OpenSource Together platform provides a comprehensive REST API for managing projects, users, tech stacks, and categories. Our API is designed to be intuitive, well-documented, and easy to integrate with your applications.

## Base URL

```
http://localhost:4000
```

## Authentication

Most endpoints require authentication. The API uses cookie-based authentication with Better Auth. Include credentials in your requests:

```typescript
fetch("http://localhost:4000/api/users/me", {
  credentials: "include",
});
```

## Response Format

All API responses follow a consistent format:

```json
{
  "data": {
    /* response data */
  },
  "timestamp": "2025-09-03T13:04:43.353Z"
}
```

Error responses:

```json
{
  "error": {
    "message": "Error message",
    "code": "ERROR_CODE",
    "details": {}
  },
  "timestamp": "2025-09-03T13:04:43.353Z"
}
```
