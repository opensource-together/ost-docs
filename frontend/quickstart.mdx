## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/opensource-together/opensource-together.git
cd opensource-together
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Environment Setup

Copy the environment file and configure your variables:

```bash
cp .env.example .env
```

```bash
# API Configuration
NEXT_PUBLIC_API_URL=http://localhost:4000
INTERNAL_SERVER_API_URL=http://localhost:4000

# Frontend URL
NEXT_PUBLIC_FRONTEND_URL=http://localhost:3000

# S3 Bucket for Metadata Assets
NEXT_PUBLIC_METADATA_ASSETS_S3_BUCKET=
```

### 4. Start Development Server

```bash
pnpm dev
```

The development server uses **Turbopack** (Next.js's fast bundler) for optimal performance. Your application will be available at <a href="http://localhost:3000">[http://localhost:3000](http://localhost:3000)</a>.

<Success>
  <strong>Success!</strong> You should see the OpenSource Together dashboard
  running locally.
</Success>

## Project Structure

After installation, your project structure should look like this:

```txt
opensource-together/
├── src/
│   ├── app/              # Next.js App Router
│   ├── features/         # Feature-based modules
│   ├── shared/           # Reusable components and utilities
│   ├── config/           # Global configuration
│   └── types/            # Global TypeScript types
├── public/               # Static assets
├── components.json       # shadcn/ui configuration
└── package.json          # Dependencies and scripts
```

## Common Issues

<AccordionGroup>
  <Accordion title="Port Already in Use">
    If port 3000 is already in use:
    <CodeBlock language="bash">

    </CodeBlock>
  </Accordion>

<Accordion title="Environment Variables Not Loading">
  Ensure your <code>.env</code> file is in the app directory and restart the
  development server.
