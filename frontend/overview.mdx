## Introduction

The OpenSource Together frontend is a modern, scalable Next.js application built with a feature-based architecture. It provides a comprehensive dashboard for discovering and growing open-source projects with your community.

## Architecture Principles

The frontend follows a **feature-based architecture** with clear separation of concerns:

<Info>
  **Core Principle**: Each feature is an autonomous module with its own
  components, hooks, services, and state management.
</Info>

### Key Architectural Decisions

1. **Feature-Based Organization**: Business logic is organized by features rather than technical layers
2. **Hybrid State Management**: Server state (TanStack Query) and client state (Zustand) are clearly separated
3. **Type Safety**: Full TypeScript coverage with Zod runtime validation
4. **Performance Optimization**: Intelligent caching, code splitting, and optimized re-renders
