## Welcome to OpenSource Together!

OpenSource Together is a comprehensive platform that helps you discover, grow, and contribute to open-source projects with your community. Our platform combines intelligent recommendations, community features, and powerful tools to make open-source collaboration more accessible and engaging.

## Platform Overview

Our platform consists of four main components working together to provide a seamless experience:

<CardGroup cols={2}>
  <Card title="Frontend" icon="palette" href="/frontend/overview">
    Modern Next.js application with feature-based architecture, providing an
    intuitive user interface for discovering and managing open-source projects.
  </Card>
  <Card title="Backend" icon="server" href="/backend/overview">
    Robust NestJS API with PostgreSQL and Prisma, handling authentication, data
    management, and business logic.
  </Card>
  <Card title="AI Engine" icon="brain" href="/ai/overview">
    Intelligent recommendation system powered by machine learning, providing
    personalized project suggestions and insights.
  </Card>
  <Card title="Documentation" icon="book-open" href="/docs">
    Comprehensive documentation built with Mintlify, providing guides, API
    references, and best practices.
  </Card>
</CardGroup>

## Key Features

<AccordionGroup>
  <Accordion title="Intelligent Recommendations">
    Our AI-powered recommendation system analyzes your interests, activity
    patterns, and project preferences to suggest the most relevant open-source
    projects for you to explore and contribute to.
  </Accordion>
  <Accordion title="Community Dashboard">
    Track your open-source journey with comprehensive analytics, contribution
    history, and community engagement metrics. See your impact and growth over
    time.
  </Accordion>
  <Accordion title="Project Management">
    Create and manage projects from GitHub or start from scratch. Organize your
    repositories, track issues, and coordinate with your community.
  </Accordion>
  <Accordion title="Secure Authentication">
    Seamless GitHub OAuth integration with secure JWT-based authentication. Your
    data is protected with industry-standard security practices.
  </Accordion>
</AccordionGroup>

## Technology Stack

<CardGroup cols={2}>
  <Card title="Frontend" icon="react">
    - Next.js 15 with App Router - TypeScript for type safety - Tailwind CSS for
    styling - TanStack Query + Zustand for state management
  </Card>
  <Card title="Backend" icon="node-js">
    - NestJS framework - PostgreSQL with Prisma ORM - JWT authentication - Redis
    for caching
  </Card>
  <Card title="AI Engine" icon="python">
    - Python 3.13+ for ML processing - Go 1.24+ for high-performance API - dbt
    for data transformation - MLflow for model tracking
  </Card>
  <Card title="Infrastructure" icon="cloud">
    - Docker containerization - GitHub Actions CI/CD - PostgreSQL with vector
    extensions - Redis caching layer
  </Card>
</CardGroup>
