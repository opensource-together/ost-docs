## Welcome

**OpenSource Together** helps people find open-source projects worth contributing to, and
helps maintainers find contributors. This site is the documentation for the people building
it: you.

<Card title="Run the app in two commands" icon="rocket" href="/quickstart" horizontal>
  No database, no Docker, no API keys. Really.
</Card>

## What's open source

<CardGroup cols={3}>
  <Card title="Web App" icon="palette" href="/web-app/overview">
    **Open source. Contribute here.** The Next.js web app: project discovery, profiles,
    dashboard, and the Learn knowledge base.
  </Card>
  <Card title="API" icon="server" href="/api-reference/introduction">
    **Closed source.** A private service. You don't need it: its contract is fully documented
    and mocked locally.
  </Card>
  <Card title="AI Engine" icon="brain" href="/ai/overview">
    The data and machine-learning pipeline that collects and ranks project data. Separate
    repository.
  </Card>
</CardGroup>

<Info>
  **The API is not open source today**, so you can't run it locally, and you don't have to.
  The repository ships a complete local mock of the API with realistic seed data, so
  every screen and flow works offline. See the [Mock API guide](/web-app/mock-api).
</Info>

## Technology
