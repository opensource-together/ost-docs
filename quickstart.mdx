## Welcome to OpenSource Together! 🚀

This quickstart guide will help you get the entire OpenSource Together platform running locally in just a few steps. Our platform consists of four main components working together to provide a comprehensive open-source project discovery and collaboration experience.

Before you begin, ensure you have the following installed:

## Step 1: Clone and Install

### 1.1 Clone the Repository

```bash
git clone https://github.com/opensource-together/opensource-together.git
cd opensource-together
```

### 1.2 Install Dependencies

<AccordionGroup>
  <Accordion title="Root Dependencies">
    ```bash # Install root dependencies pnpm install ```
  </Accordion>
  <Accordion title="Frontend Dependencies">
    ```bash cd apps/ost-frontend pnpm install ```
  </Accordion>
  <Accordion title="Backend Dependencies">
    ```bash cd apps/ost-backend npm install ```
  </Accordion>
  <Accordion title="AI Engine Dependencies">
    ```bash cd apps/ost-ai-engine pip install uv uv sync --group dev ```
  </Accordion>
</AccordionGroup>

## Step 2: Environment Configuration

### 2.1 Frontend Environment

```bash
cd apps/ost-frontend
cp .env.example .env.local
```

Configure these variables in `.env.local`:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_API_URL=http://localhost:3001
NEXT_PUBLIC_GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
```

### 2.2 Backend Environment

```bash
cd apps/ost-backend
cp .env.example .env
```

Configure these variables in `.env`:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/ost_backend"
JWT_SECRET="your-super-secret-jwt-key"
GITHUB_CLIENT_ID="your_github_client_id"
GITHUB_CLIENT_SECRET="your_github_client_secret"
PORT=3001
```

### 2.3 AI Engine Environment

```bash
cd apps/ost-ai-engine
cp .env.example .env
```

Configure these variables in `.env`:

```env
DATABASE_URL=postgresql://user:password@localhost:5434/OST_PROD
REDIS_CACHE_URL=redis://localhost:6379/0
GITHUB_ACCESS_TOKEN=your_github_token
MLFLOW_TRACKING_URI=sqlite:///logs/mlflow.db
GO_API_PORT=8080
```

## Step 3: Start Services

### 3.1 Database Services

<AccordionGroup>
  <Accordion title="Start Backend Database">
    ```bash cd apps/ost-backend docker compose up -d ```
  </Accordion>
  <Accordion title="Start AI Engine Database">
    ```bash cd apps/ost-ai-engine docker-compose up -d db redis ```
  </Accordion>
</AccordionGroup>

### 3.2 Database Setup

<AccordionGroup>
  <Accordion title="Backend Database Setup">
    ```bash cd apps/ost-backend npx prisma generate npx prisma migrate dev npx
    prisma db seed ```
  </Accordion>
  <Accordion title="AI Engine Database Setup">
    ```bash cd apps/ost-ai-engine psql -d OST_PROD -f
    scripts/database/recreate_schema.sql uv run python
    scripts/database/create_test_users.py ```
  </Accordion>
</AccordionGroup>

## Step 4: Start Applications

You'll need multiple terminal windows for this step:

<AccordionGroup>
  <Accordion title="Terminal 1: Frontend">
    ```bash cd apps/ost-frontend pnpm dev ``` Available at:
    http://localhost:3000
  </Accordion>
  <Accordion title="Terminal 2: Backend">
    ```bash cd apps/ost-backend npm run start:dev ``` Available at:
    http://localhost:3001
  </Accordion>
  <Accordion title="Terminal 3: AI Engine Pipeline">
    ```bash cd apps/ost-ai-engine uv run dagster dev ``` Dagster UI at:
    http://localhost:3000 (if not occupied)
  </Accordion>
  <Accordion title="Terminal 4: AI Engine API">
    ```bash cd apps/ost-ai-engine/src/api/go go build -o recommendations-api
    recommendations.go ./recommendations-api ``` API available at:
    http://localhost:8080
  </Accordion>
</AccordionGroup>

## Step 5: Verify Installation

<AccordionGroup>
  <Accordion title="Frontend Check">
    Open http://localhost:3000 and verify the OpenSource Together dashboard loads.
  </Accordion>
  <Accordion title="Backend Check">
    ```bash
    curl http://localhost:3001/health
    ```
    Should return: `{"status":"ok","timestamp":"..."}`
  </Accordion>
  <Accordion title="AI Engine Check">
    ```bash
    curl http://localhost:8080/health
    ```
    Should return: `{"status":"healthy","timestamp":"..."}`
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port Conflicts">
    If you encounter port conflicts: - Frontend: `pnpm dev -- -p 3001` -
    Backend: Change `PORT=3002` in `.env` - AI Engine API: Change
    `GO_API_PORT=8081` in `.env`
  </Accordion>
  <Accordion title="Database Connection Issues">
    Ensure Docker is running: ```bash docker ps docker compose down && docker
    compose up -d ```
  </Accordion>
  <Accordion title="Environment Variables">
    Make sure all `.env` files are properly configured and restart the services.
  </Accordion>
</AccordionGroup>
