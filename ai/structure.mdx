        cfg.py                  # Generates cfg.yaml from .env

    src/
        dagster/
            assets.py             # Assets (scrape → rank → map → insert)
            dagster.yaml          # Dagster instance settings
            definitions.py        # Jobs, schedules, asset checks
            config/
                cfg_resource.py     # Dagster resource providing PipelineConfig
                load_cfg.py         # PipelineConfig loader (reads cfg.yaml)
                map/
                    mapping_map.py    # Centralized GitHub & GitLab mappings

    services/
        go/
            github/
                go.mod, go.sum, main.go    # builds /app/github-scraper
            gitlab/
                go.mod, go.sum, main.go    # builds /app/gitlab-scraper

    ## Mapping Logic

    Mappings between scraper fields and the unified Project model are centralized in `src/dagster/config/map/mapping_map.py`.
    They are static Python dictionaries imported by assets (not Dagster resources), keeping the code simple and predictable.
