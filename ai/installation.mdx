
# Installation & Deployment Guide

This guide explains how to set up, configure, and deploy the OST AI Engine platform.

## Requirements
- OS: Linux, macOS, Windows
- Python = 3.13.7
- Go >= 1.20
- Node.js (for Prisma)
- Docker

## Environment Variables
Copy `.env.example` to `.env` and fill in:

```ini
POSTGRES_DB=db_name
POSTGRES_USER=db_user
POSTGRES_PASSWORD=db_password

DATABASE_URL=postgresql://<db_user>:<db_password>@localhost:port/<db_name>

GITHUB_ACCESS_TOKEN=your_github_access_token_here
GITLAB_ACCESS_TOKEN=your_gitlab_access_token_here
```

| Variable              | Description                  | Example |
|-----------------------|-----------------------------|---------|
| DATABASE_URL          | PostgreSQL connection URL    | postgresql://db_user:db_password@localhost:port/db_name |
| POSTGRES_DB           | Database name                | db_name |
| POSTGRES_USER         | Database user                | db_user |
| POSTGRES_PASSWORD     | Database password            | db_password |
| GITHUB_ACCESS_TOKEN   | GitHub API token             | your_github_access_token_here |
| GITLAB_ACCESS_TOKEN   | GitLab API token             | your_gitlab_access_token_here |

```bash
go mod tidy ./src/infrastructure/services/go/github

```
```bash
cd prisma
npm install
```

## Database Setup
Start the PostgreSQL database using Docker Compose:
```bash
docker compose up -d
```

## Prisma Migrations
Apply database migrations:
```bash
cd prisma
npx prisma migrate deploy
```

## Dagster & Pipelines
Launch Dagster and the pipeline:
```bash
export DAGSTER_HOME="$PWD/src/dagster"
poetry run dagster dev -m src.dagster.definitions --host 127.0.0.1 --port 3000
```

Dagster UI: [http://localhost:3000](http://localhost:3000)

The `github_scraper_job` runs every 6 hours (cron: `0 */6 * * *`).
Go scrapers are integrated as Dagster assets and run automatically. No DevOps action needed.

## Project Structure
```python
src/
	dagster/                          # Dagster pipeline and orchestration
		assets.py                     # Dagster asset definitions (data pipeline steps)
		dagster.yaml                  # Dagster instance configuration
		definitions.py                # Dagster job and schedule definitions
		config/                       # Pipeline configuration files
			config.py                 # PipelineConfig class and settings
			github_mapping.py         # Mapping GitHub data to project model
			local.yaml                # Local Dagster config (optional)
			prod.yaml                 # Production Dagster config (optional)
	infrastructure/
		services/
			go/
				github/
					go.mod            # Go module definition for GitHub scraper
					main.go           # Go GitHub scraper source code
					main_test.go      # Tests for GitHub scraper
				gitlab/
					go.mod            # Go module definition for GitLab scraper
					main.go           # Go GitLab scraper source code
					main_test.go      # Tests for GitLab scraper
prisma/
	schema.prisma                     # Prisma schema (DB models)
	migrations/                       # Prisma migration files
	seed/                             # Seed scripts for DB
docs/
	ai/*.mdx                          # AI Engine documentation (Mintlify)
```

## Example Python Dockerfile
```dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY pyproject.toml poetry.lock ./
RUN pip install poetry && poetry install --no-root
COPY src/ src/
COPY .env .env
ENV DAGSTER_HOME=/app/src/dagster
CMD ["poetry", "run", "dagster", "dev", "-m", "src.dagster.definitions", "--host", "127.0.0.1", "--port", "3000"]
```
